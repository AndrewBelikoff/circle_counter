# Circle Counter

Android-приложение для подсчёта кругов по повторяющемуся GPS-маршруту (стадион, парк, городское кольцо любой формы).

## Идея

1. **Старт** — запись GPS + секундомер.
2. **Новый трек** — после Старта бегун уже на кольце; когда паттерн кругов подтверждается (примерно на 3-м проходе), счётчик **пересчитывает все круги с начала движения** и показывает актуальный номер (не «только что нашли 1-й»).
3. Если гипотеза не подтвердилась к **Стопу** — «не удалось определить круги»: GPX выгрузить можно, сохранить как кольцо — нельзя.
4. **Известный трек** («домашний стадион») — эталон уже есть, круги с первого; данные накапливаются и уточняют контур.
5. Время **не** участвует в детекции кругов (только UI и темп).
6. С автосчёта показываются три дистанции (с хвостом неполного круга): GPS / ручная длина / вычисленная длина трека.
7. После Стопа на **новом** треке с подтверждёнными кругами: **добавить к существующему** / **сохранить как новый** / **отмена** (авто-имя `yy-MM-dd_HH:mm`, хранятся последние 10). Список треков — по свежести.
8. GPS-фильтр: отбрасывает скачки быстрее ~10 с/100 м и spike-return; лёгкое сглаживание пути перед детекцией кругов.

## Сборка

Нужны `ANDROID_HOME` и JDK 17+ с `javac` (в `gradle.properties` указан локальный Temurin 21).

```bash
export ANDROID_HOME=/home/ble/Android/Sdk
./gradlew :app:assembleDebug
./gradlew :app:testDebugUnitTest
```

APK: `app/build/outputs/apk/debug/app-debug.apk`

## Установка на телефон

```bash
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

Нужны разрешения: точная геолокация, уведомления, Bluetooth (скан/подключение); для фона GPS — «всегда» (Android спросит отдельно).

## Пульсометр (Coospo HW9 и др.)

Стандартный BLE Heart Rate Service (`0x180D`). На главном экране: **Найти HW9** → выбрать датчик → пульс на экране бега.

Не сопрягайте HW9 в системных настройках Bluetooth — только из приложения.
